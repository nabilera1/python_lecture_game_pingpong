> **3부 함수와 자료구조로 게임 다듬기** · 10차시 · 6단계 모형: **구현**  
> 게임: 가위바위보 판정표 버전  
> 핵심 개념: 2차원 리스트, 행, 열, 중첩 반복, enumerate, 튜플 반환

## 학습 목표

1. 2차원 리스트를 만들고 [행][열] 인덱싱으로 값을 읽을 수 있다.
2. 중첩 반복문으로 표 형태의 데이터를 처리하고 출력할 수 있다.
3. 게임 규칙(판정표)과 기록(기록표)을 2차원 리스트로 모델링할 수 있다.

## 핵심 질문

> **표(행과 열)로 된 규칙과 기록은 어떤 자료구조에 담아야 할까?**

3차시에 그린 가위바위보 판정 표를 기억하나요? 행은 '나', 열은 '컴퓨터'인 3 × 3 표였습니다.
이 표를 **그대로 코드로 옮긴 것이 2차원 리스트**입니다. 경기 기록(라운드, 나, 컴퓨터, 결과)도 한 줄씩 쌓이는 표이므로 2차원 리스트로 저장할 수 있습니다.

## 2차원 리스트 = 리스트 안의 리스트

```python
TABLE = [[0, 2, 1],   # 0행 나: 가위
         [1, 0, 2],   # 1행 나: 바위
         [2, 1, 0]]   # 2행 나: 보
#        가위 바위 보  ← 열: 컴퓨터

print(TABLE[1])       # [1, 0, 2]  ← 1행 전체
print(TABLE[1][0])    # 1          ← 1행 0열 (나 바위, 컴퓨터 가위 → 이김)
print(len(TABLE), len(TABLE[0]))   # 3 3  (행 개수, 열 개수)
```

**첫 번째 [ ]는 행, 두 번째 [ ]는 열**입니다. 순서를 바꾸면 결과가 반대가 되니 주의하세요!

## 판정표로 승패 구하기

```python
RESULT_TEXT = ["비김", "이김", "짐"]

def play_match(win_goal=2):
    score = {"이김": 0, "짐": 0, "비김": 0}
    records = []                                      # 기록표 (2차원 리스트)
    while score["이김"] < win_goal and score["짐"] < win_goal:
        me, cpu = get_pick(), random.randrange(3)     # 둘 다 인덱스(0~2)
        result = RESULT_TEXT[TABLE[me][cpu]]          # 표에서 찾기 → 문구
        score[result] += 1
        records.append([len(records) + 1, CHOICES[me], CHOICES[cpu], result])
    return records, score["이김"] == win_goal         # 값 2개 반환 (튜플)
```

`return a, b`처럼 쓰면 값 두 개를 묶어서(튜플) 돌려주고, `records, won = play_match()`로 나눠 받을 수 있습니다.

## 중첩 반복으로 기록표 출력

```python
def print_records(records):
    for row in [["라운드", "나", "컴퓨터", "결과"]] + records:   # 바깥: 행
        for item in row:                                       # 안쪽: 칸
            print(f"{item!s:<5}", end="| ")
        print()                                                # 행이 끝나면 줄 바꿈
```

```text
라운드  | 나    | 컴퓨터  | 결과   |
1     | 바위   | 가위   | 이김   |
2     | 보    | 보    | 비김   |
```

- `:<5` : 5칸 너비로 왼쪽 정렬, `end="| "` : 줄을 바꾸지 않고 `| `로 끝냄
- 안쪽 반복이 한 번 다 돌 때마다 바깥 반복이 한 번 진행됩니다. 3행 × 4칸이면 print는 12번 + 줄 바꿈 3번

## 행·열 반복과 enumerate

```python
grid = [list("..#"), list(".M."), list("#..")]
for r, row in enumerate(grid):          # enumerate: (번호, 값)
    for c, ch in enumerate(row):
        if ch == "M":
            print("몬스터 위치:", (r, c))   # (1, 1)
```

이 격자 구조는 12차시 **던전 탈출** 게임의 지도가 됩니다.
